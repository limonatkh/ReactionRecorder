# خطة برنامج الكمبيوتر (غرفة التحكم) + إضافات الجوال

آخر تحديث: 22 نوفمبر 2026. الكمبيوتر: **ويندوز**. الشغل من Claude Code على اللابتوب، بنفس المستودع.

## الفكرة
اللابتوب بيصير **المدير (الـ hub)** بدل الجوال. الجوالات بترتبط فيه بنفس الباركود، وكل جهاز بيضل يسجّل عنده بجودة كاملة. اللابتوب بيعرض المعاينة والحالة، وبيتحكم بكل إشي، وبيسجّل المايكات الموصولة فيه، وبيجمع الملفات بعد الإيقاف.

**بدون أي حد لعدد الأجهزة أو المايكات بالكود.** (الحد العملي من الشبكة: هوتسبوت الجوال حوالي ١٠ أجهزة، الراوتر ٣٠+. البرنامج بينبّه.)

## التقنية المقترحة
- **Kotlin + Compose Desktop (JVM)**: نفس لغة تطبيق الجوال. بنطلع الكود المشترك (البروتوكول، الجلسة، الإعداد) لمكتبة `shared/` بدون أندرويد، وبيستعملها الطرفين.
- الصوت من مايكات ويندوز: `javax.sound.sampled` (كل مايك/مدخل = Mixer، اسمه ظاهر)، تسجيل WAV لكل مايك مع ساعة الجلسة.
- التغليف: `packageMsi` / `packageExe` من Compose (ملف تثبيت لويندوز). يتبنى على GitHub (runner ويندوز، مجاني لأنه المستودع عام) أو محليًا.
- الشبكة: نفس البروتوكول بالزبط — `docs/PROTOCOL.md`. تطبيق الجوال الحالي لازم يرتبط باللابتوب بدون ما يتغير إشي فيه بالمرحلة الأولى.

## شاشة اللابتوب
- **شبكة معاينة**: خانة لكل كمرة (صورة صغيرة كل ٢–٥ ثواني، إنت بتختار، مش بث مباشر)، وتحتها الاسم، الدور، الجودة، البطارية، المساحة بالساعات، السخونة، الواي فاي، 🔴 بيسجّل / 🟢 جاهز / ⚪ مقطوع.
- **قائمة المايكات**: كل مايك (جوال أو موصول باللابتوب) مع مستوى صوت حي، اسم قابل للتعديل، و**ربطه بكمرة/شخص**.
- **شريط الجلسة**: ابدأ للكل، إيقاف مؤقت، إيقاف (ضغطة مطوّلة ثانية)، الوقت، علامات ⭐ ✖ (أزرار كيبورد)، زر «فحص سريع».
- **تنبيهات**: جهاز انقطع، مايك ساكت فترة، صوت عالي لدرجة التشويش، بطارية ضعيفة، جوال سخن، مساحة قليلة.
- **بعد الإيقاف**: تقدّم جمع الملفات من كل جهاز، وبعدين «ابعت الجلسة للجوال للمونتاج» (المونتاج على الكمبيوتر مرحلة لاحقة).

## التحكم الكامل بكل كمرة (من اللابتوب)
- فوكس: لمسة على المعاينة، **قفل الفوكس** (ما يتغير لو الشخص تحرك)، فوكس يدوي بالمسافة إذا الجوال بيدعم.
- إضاءة: تعويض + **قفل الإضاءة**.
- توازن الألوان: تلقائي / شمس / غيم / داخلي + قفل.
- زوم، تبديل أمامي/خلفي/واسعة (إذا متاحة)، الجودة 720/1080، الإطارات 24/30، تثبيت الصورة، ضو الفلاش، قفل الاتجاه، خطوط مساعدة على المعاينة.
- إعادة تشغيل كمرة الجهاز عن بعد، تغيير دوره (مايك / كمرة / الاثنين)، اسمه.

## التحكم بكل مايك
- التكبير، كتم، الوضع (صوته بس / طبيعي / المحيط)، تنبيه التشويش والسكوت.
- مايكات اللابتوب: أي عدد، كل مدخل لكرت صوت متعدد = مايك لحاله، تسمية + ربط بكمرة.

## توفير البطارية على الجوالات (إعداد لكل جهاز أو للكل)
- **إطفاء الشاشة فعليًا بعد بدء التسجيل** (مش تعتيم):
  - «فوري»: قفل الشاشة عن طريق إذن مسؤول الجهاز (Device Admin → `lockNow`)، موافقة مرة وحدة.
  - «بعد ١٠ ثواني»: تغيير مدة انطفاء الشاشة وقت التسجيل وإرجاعها بعده (إذن تعديل إعدادات النظام).
  - ⚠ الكمرة والشاشة مطفية: لازم فحص على سامسونج. التطبيق بيفحص لحاله إنه الصور لسا عم تنكتب، وبينبّه اللابتوب إذا وقفت.
- ما في رسم واجهة والشاشة مطفية، المعاينة أبطأ تلقائيًا (أو مطفية)، بدون اهتزاز/أصوات، ٣٠ إطار ثابت.
- إرسال السخونة (`PowerManager.getCurrentThermalStatus`) وقوة الواي فاي ضمن `lvl`.

## إضافات لازمة على تطبيق الجوال (بروتوكول نسخة 2، متوافقة مع القديم)
- `cfg`: `afLock` (قفل/فك الفوكس بعد اللمسة)، `aeLock`، `awb` (+ قفل)، `focusDist` (يدوي)، `fps`، `lens`، `screenOff` (off/now/10s)، `saver`، `restartCam`، `name`.
- `caps`: `manualFocus`، `lenses`، `fpsRanges`، `awbModes`.
- `lvl`: `temp` (حالة السخونة)، `rssi`، `drops` (إطارات ضايعة)، `camOk` (الكمرة عم تكتب).
- `mark` من اللابتوب (⭐ ✖)، `check` (تسجيل فحص ٥ ثواني ورفعه فورًا للسماع).

## المراحل
1. **الأساس**: نقل الكود المشترك لـ `shared/`، برنامج ويندوز بيشغّل الـ hub، الباركود على الشاشة، الجوالات بترتبط، شبكة المعاينة والحالة. (اختبار: جوال + لابتوب على نفس الواي فاي.)
2. **التسجيل**: ابدأ/أوقف للكل، مايكات اللابتوب (أي عدد، تسمية، ربط)، جمع الملفات، ساعة موحّدة.
3. **التحكم الكامل**: كل خيارات الكمرة والمايك فوق + قفل الفوكس/الإضاءة + إضافات الجوال (بروتوكول 2).
4. **البطارية والتنبيهات**: إطفاء الشاشة الفعلي، وضع التوفير، السخونة، الواي فاي، الفحص السريع.
5. **التسليم للمونتاج**: إرسال الجلسة من اللابتوب للجوال (ولاحقًا مونتاج على الكمبيوتر).

كل مرحلة: تجربة حقيقية على اللابتوب مع جوال واحد على الأقل قبل ما تكمل للي بعدها، وتقرير صريح بشو انجرب وشو لأ.
