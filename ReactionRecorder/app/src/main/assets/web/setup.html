المتصفح ما بيفتح الكاميرا والمايك إلا بصفحة آمنة (HTTPS). جوال المدير عامل شهادة محلية بتشتغل بدون إنترنت. بتثق فيها مرة وحدة بس على هالجهاز، وبعدها كل جلسة بتفتح على طول. الشهادة محصورة بعناوين الشبكة المحلية — ما بتنفع لأي موقع على الإنترنت.

بصمة الشهادة: … — لازم تطابق اللي على شاشة جوال المدير.

iPhone / iPad (Safari)

  1. ⬇ نزّل البروفايل ← اكبس «Allow / سماح».
  2. افتح الإعدادات ← فوق رح تلاقي «تم تنزيل ملف التعريف» ← تثبيت (ورمز القفل) ← تثبيت.
  3. الإعدادات ← عام ← حول ← إعدادات الثقة بالشهادات ← فعّل ReactionRecorder Local.
  4. ارجع لـ Safari على هالصفحة — بتكمّل لحالها.

أندرويد (Chrome)

  1. ⬇ نزّل الشهادة
  2. افتح الإعدادات ← الأمان والخصوصية ← إعدادات أخرى/المزيد ← التشفير وبيانات الاعتماد ← تثبيت شهادة ← شهادة CA ← «ثبّت على أي حال» ← اختار الملف ReactionRecorder-local.crt.
    (الأسماء بتختلف شوي حسب الجوال — ابحث بالإعدادات عن «شهادة CA».) التحذير طبيعي لأي شهادة محلية.
  3. ارجع لـ Chrome على هالصفحة — بتكمّل لحالها.

ويندوز (Chrome / Edge)

  1. ⬇ نزّل الشهادة وافتح الملف.
  2. Install Certificate ← Current User ← Place all certificates in the following store ← Browse ← Trusted Root Certification Authorities ← Next ← Finish ← Yes.
  3. سكّر المتصفح كله وافتحه من جديد، وارجع لهالرابط.

Firefox: من الإعدادات ← Certificates ← View ← Authorities ← Import، وفعّل «Trust this CA to identify websites».

ماك (Safari / Chrome)

  1. ⬇ نزّل الشهادة وافتحها (بتفتح Keychain Access).
  2. دبل كليك على ReactionRecorder Local ← Trust ← When using this certificate: Always Trust.

مش متأكد شو جهازك؟ كل الطرق فوق — اختار اللي بتناسبك.
